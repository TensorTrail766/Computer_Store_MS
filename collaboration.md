## 5. Collaboration Rules

- Every development task must be associated with a GitHub issue.
- Team members must work on their assigned branches.
- Changes must follow the established coding conventions.
- Pull requests must be reviewed before merging.
- Relevant tests must be completed before task closure.
- Documentation must be updated alongside implementation.
- Sensitive information must not be committed.
- Major technical changes must be discussed with the team.

## 6. Communication and Progress Reporting

Team members participate in regular development meetings to discuss:

- Completed tasks.
- Current development activities.
- Technical difficulties.
- Module dependencies.
- Integration requirements.
- Upcoming assignments.

GitHub Issues and project boards are used to maintain task assignments and development progress.
